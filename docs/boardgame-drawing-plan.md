# 주루마블 배경 그림 기능 계획

## 범위

이 문서는 구현 전 계획이다. 그림 편집기, 그림 관리 패널, 타일 연결과 저장 방식을 정의한다.

사용자는 512×819 또는 512×512 중 하나를 선택해 그림을 만든다. 일반 외부 타일에는 세로형, 코너·내부 타일에는 정사각형을 권장하며 사용자가 직접 선택할 수 있다.

## 진입과 화면 구성

타일 편집기의 배경 색상·제목 색상 오른쪽에 ‘배경 그리기’ 버튼을 배치한다. 누르면 오른쪽 사이드바가 그림 관리 패널로 전환된다. ‘타일 편집으로 돌아가기’로 복귀한다. 모바일에서는 기존 사이드바 위치에 같은 패널을 표시한다.

패널은 그림 목록, 선택한 그림의 사용 현황, 새 그림·적용·복제·수정·삭제 기능을 제공한다. 선택한 타일과 현재 연결한 그림을 명확히 표시한다.

### 타일에 적용 후 그리기

1. 선택한 타일에 새 그림 또는 기존 그림을 연결한다.
2. 게임판에서 선택한 타일에 초안이 보이도록 표시한다.
3. 포인터를 타일 표면 좌표에서 그림 좌표로 변환해 그린다. 그림 입력 중에는 보드 드래그·타일 이동 입력을 잠근다.
4. 저장하면 원본 그림을 갱신하고 연결된 모든 타일에 반영한다.

새 그림은 편집 세션의 초안으로 연결해 미리 보여준다. 저장 시 이미지 생성과 타일 연결을 확정한다. 취소하면 기존 연결을 복원하고 초안 파일을 정리한다.

### 전용 그리기 모드

선택한 해상도의 평면 캔버스를 표시한다. 저장 후 적용할 타일을 선택할 수 있다. 전용 모드와 타일 위 그리기는 동일한 브러시 상태와 편집 로직을 사용한다.

도구의 초기 범위는 펜 색상·굵기·불투명도, 지우개, 실행 취소·다시 실행, 전체 지우기이다. 투명 영역 아래에는 체크무늬를 표시한다. 펜 불투명도와 타일에 적용하는 그림 전체 불투명도는 별도로 조절한다.

그림은 투명 배경으로 저장하고 렌더링은 타일 배경색 → 그림 → 타일 제목 순서로 합성한다. 제목 색상은 기존 타일 속성을 따른다.

## 이미지 재사용과 보호

- 재적용은 같은 그림 ID를 연결한다. 적용할 때마다 파일을 복제하지 않는다.
- 복제는 별도 그림 ID와 파일을 생성해 독립적으로 수정한다.
- 원본을 수정하면 같은 ID를 참조하는 모든 타일에 반영한다.
- 목록에서 ‘현재 타일에 적용’, ‘다른 타일에 적용 중’, 적용 개수를 표시한다. 사용 현황에서 보드와 타일을 확인한다.
- 다른 타일에서도 사용하는 원본은 기본적으로 편집 잠금 상태로 연다. ‘원본 수정’ 시 영향받는 타일 목록과 개수를 보여주고 확인받는다.
- ‘복제 후 수정’을 함께 제공한다. 이 동작은 선택한 타일의 연결만 새 그림으로 바꾼다.
- 사용 중인 그림 삭제는 적용 위치를 보여주고 확인받는다. 확인하면 연결을 해제하고 타일은 배경색·제목만 표시한다.
- 그림 적용 해제와 원본 삭제는 별도 동작으로 제공한다.

확인 없이 다른 타일의 공유 원본을 바꾸는 일을 방지하면서, 명시적으로 원본을 수정하면 전체에 반영한다.

## 격자 크기 변경

그림 ID와 해상도는 타일 형태와 독립적으로 유지한다. 일반 외부 타일이 코너가 되거나 그 반대가 되어도 원본 파일을 변형하지 않는다.

초기 표시 방식은 contain으로 제안한다. 전체 그림을 타일 중앙에 맞추고 남는 부분에는 타일 배경색을 표시한다. 이미지 전체 불투명도는 타일 연결별 속성으로 둔다.

비율을 바꾸려면 새 해상도로 복제하고 그림을 중앙에 맞춰 옮긴 뒤 편집한다. 공유 원본의 캔버스 비율을 즉시 변경하는 기능은 초기 범위에서 제외한다.

격자 축소로 삭제되는 타일은 그림 연결도 함께 삭제한다. 원본 그림은 관리 목록에 보관하며 사용 개수만 감소한다.

## 저장과 권한

### 제안 데이터 모델

- boardgame_drawings에 ID, 소유자 UUID, 이름, 너비·높이, 파일 경로, 버전, 생성·수정 시각을 저장한다.
- 타일에는 drawing_id와 drawing_opacity를 추가한다. 삭제 시 연결 해제를 위해 외래 키는 ON DELETE SET NULL을 사용한다.
- 그림 소유자와 super_admin이 원본을 수정·삭제한다. 보드 편집자는 사용할 수 있는 그림을 자신의 편집 가능 타일에 연결한다.
- 초기 라이브러리는 개인 소유 그림과 현재 보드에 이미 연결된 그림으로 구성한다. 다른 소유자의 그림은 원본 수정 권한 없이 재적용 또는 복제한다.
- 비공개 보드의 사용 현황은 조회자의 보드 접근 권한에 따라 제한한다. 권한 없는 보드 이름·타일 정보는 노출하지 않는다.

여러 소유자의 보드에서 원본을 공유할 수 있는지, 타인 그림 복제를 어디까지 허용할지는 구현 전에 확정할 정책이다.

### 저장 흐름

브러시 입력과 undo 기록은 브라우저에서 처리한다. 저장 시 투명 WebP로 인코딩하고 서버를 통해 업로드한다. 무료 플랜의 서버 이미지 변환 기능에 의존하지 않는다.

서버에서 세션·그림 소유권·보드 편집 권한, 실제 이미지 형식·해상도·용량을 검사한다. 업로드와 파일 제공은 서버 경로를 사용해 Supabase SDK와 키를 브라우저에 노출하지 않는다. 버킷은 비공개로 구성한다.

새 버전 파일을 업로드한 뒤 DB의 경로와 버전을 조건부 갱신한다. 충돌 시 저장 실패를 알리고 초안을 유지한다. DB 갱신에 실패한 업로드는 정리하고, 성공한 이전 버전 파일도 정리한다. 저장된 버전으로 캐시를 구분한다.

Realtime 변경 알림에는 그림 버전 변경도 포함한다. 클라이언트는 권한을 확인한 뒤 연결된 타일 텍스처를 다시 합성한다. 보드의 다른 속성을 수정하거나 카메라를 이동할 때 이미지를 다시 다운로드하지 않도록 캐시한다.

이미지의 소유권·접근 권한과 별도로 현재 타일 편집 잠금도 검사한다. 원본 동시 수정은 버전 검사 또는 그림 편집 잠금으로 충돌을 방지한다.

## 이미지 30개 적용 시 용량

계산 가정은 일반 외부 타일 26개에 512×819, 코너 4개에 512×512를 사용하고, 30개가 서로 다른 원본을 사용하는 경우이다. 단위는 KB·MB의 십진 단위와 메모리용 MiB를 구분한다.

| 항목 | 계산 | 결과 |
| --- | --- | --- |
| 세로형 픽셀 | 26 × 512 × 819 | 10,902,528픽셀 |
| 정사각형 픽셀 | 4 × 512 × 512 | 1,048,576픽셀 |
| 총 픽셀 | 두 항목 합계 | 11,951,104픽셀 |
| RGBA 기본 메모리 | 총 픽셀 × 4바이트 | 47,804,416바이트, 약 45.59MiB |
| 밉맵 포함 텍스처 추정 | 기본 메모리 × 약 4/3 | 약 60.79MiB |

밉맵 수치는 일반적인 근사값이다. 현재처럼 CanvasTexture를 타일마다 만들면 동일 원본을 재사용해도 타일별 합성 텍스처 메모리는 발생한다. 원본 이미지 디코딩 메모리와 캔버스, 편집기의 undo 기록, 기존 게임판·주사위 메모리는 위 수치에 추가된다. 따라서 위 수치를 전체 브라우저 메모리 사용량으로 해석하지 않는다.

### 파일 저장량과 전송량

압축된 파일 크기는 선의 복잡도, 투명 영역, 포맷과 품질에 따라 달라진다. 다음은 실측값이 아닌 예산 시나리오이다.

| 원본 한 개 평균 크기 | 서로 다른 그림 30개 저장 | 새로 전부 내려받는 로딩 1,000회 |
| --- | --- | --- |
| 30KB | 0.9MB | 0.9GB |
| 100KB | 3MB | 3GB |
| 200KB | 6MB | 6GB |

한 그림을 여러 타일에 연결하면 원본 저장량과 최초 다운로드는 고유 그림 개수를 기준으로 감소한다. 예를 들어 동일한 100KB 원본을 30개 타일에 적용하면 원본 파일은 100KB 하나다. 타일별 합성 텍스처 메모리는 별도다.

초기 업로드 제한은 그림당 200KB를 목표로 제안한다. 실제 샘플로 품질과 압축률을 확인한 뒤 확정한다. 투명 WebP의 손실 압축은 작은 글자·가는 선이 흐려질 수 있으므로 무손실 WebP와 비교한다. 사용자가 그린 글자 품질이 중요하면 용량 제한을 완화하는 선택도 필요하다.

Supabase 무료 플랜의 저장·전송 한도는 운영 시점의 요금표와 프로젝트 사용량에서 다시 확인한다. 특히 전송량은 캐시·비캐시 할당량이 구분되므로 표의 전송량을 단일 무료 한도와 바로 비교하지 않는다.

## 구현 순서

1. 그림 테이블·비공개 버킷·권한·버전 관리와 타일 연결을 추가한다.
2. 사이드바 그림 관리 패널에서 생성·재적용·복제·삭제·사용 현황을 제공한다.
3. 전용 평면 캔버스 편집기와 로컬 undo/redo를 구현한다.
4. 타일 위 좌표 변환과 즉시 미리보기를 연결한다.
5. 합성 텍스처·그림 전체 불투명도·원본 변경 Realtime 알림을 연결한다.
6. 격자 변경·원본 공유·동시 수정·삭제 정리와 메모리 해제를 확인한다.

## 완료 기준

- 두 해상도를 선택하고 두 모드에서 같은 결과를 그릴 수 있다.
- 저장하지 않은 브러시 입력은 네트워크 요청을 발생시키지 않는다.
- 같은 원본 재적용은 파일 복제를 발생시키지 않는다.
- 원본 수정은 모든 연결 타일에 반영되고 복제본에는 영향을 주지 않는다.
- 다른 타일에 적용된 원본은 사용 현황 확인과 명시적 확인 후 수정한다.
- 격자 형태 변경 시 비율 정책에 따라 표시하고 삭제된 타일의 연결만 정리한다.
- 사용 중 원본 삭제·권한 거부·동시 저장 실패 시 데이터와 초안을 일관되게 유지한다.
- 이미지 30개를 적용해 첫 로딩 전송량·편집 반응성·GPU 및 캔버스 메모리를 측정하고, 화면 종료 시 텍스처와 캐시를 정리한다.
