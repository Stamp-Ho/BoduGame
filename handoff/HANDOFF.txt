아발론·보드게임 이관 소스

이 묶음은 기존 Next.js App Router 프로젝트에 통합할 소스입니다. 대상 프로젝트의 루트 레이아웃, 게임 홈, 패키지 설정에 맞춰 병합하세요. 파일 경로는 원본 프로젝트 루트를 기준으로 합니다.

포함 범위
- app/avalon, app/boardgame의 화면, 게임 로직, Server Actions.
- 공통 인증과 Supabase 브라우저·서버·관리자 클라이언트, ConfirmModal.
- supabase/migrations의 게임용 SQL 11개. 기존 게임 계정, 전적, 보드 데이터, 환경 변수 실제 값은 들어 있지 않습니다.
- app/avalon/animations.css는 원본 전역 CSS에서 아발론이 쓰는 애니메이션만 옮긴 파일입니다.
- 아발론은 실명으로 프로필을 조회하는 개발용 /avalon/preview 경로를 뺐습니다. AvalonMain이 가져오는 미리보기 상수는 가상 이름과 ID를 사용합니다. 보드게임의 기본 팀 이름은 1팀~4팀으로 바꿨습니다.

대상 프로젝트에서 연결할 부분
1. App Router의 /avalon, /boardgame 경로와 공용 홈을 연결하세요. 두 게임의 복귀 링크는 /를 사용합니다. Tailwind CSS 4를 설정하고 app/avalon/animations.css를 대상 루트 레이아웃에서 가져오거나 기존 전역 스타일에 병합하세요. TypeScript의 @/* 경로 별칭은 옮긴 소스 루트를 가리켜야 합니다.
2. 원본 버전은 Next.js 16.2.11, React 및 React DOM 19.2.4입니다. 직접 의존성은 @supabase/ssr ^0.12.3, @supabase/supabase-js ^2.110.8, lucide-react ^1.26.0, @hello-pangea/dnd ^18.0.1, three ^0.186.0, cannon-es ^0.20.0, framer-motion ^12.42.2입니다. 타입·스타일 도구는 @types/three ^0.186.0, tailwindcss 및 @tailwindcss/postcss ^4를 참고하세요.
3. 포함된 로그인은 기존 12반의 이름·비밀번호 인증입니다. 새 사용자 모델에 맞춰 app/(auth)와 utils/auth.ts를 연결하거나 교체하세요. 현행 아발론 플레이어는 Auth UUID를 쓰고, 팀 편성은 public.users.id를 Auth UUID로 사용합니다. 보드게임 제작자·편집자와 편집 잠금 SQL은 public.users.username 및 Auth 메타데이터의 name에 의존합니다. 외부 가입을 열 때는 영속적인 계정 ID를 기준으로 권한을 연결하고 표시 이름을 분리하세요.
4. 새 Supabase를 사용하면 게임 SQL에 앞서 호환되는 사용자 스키마를 마련하거나 게임 SQL의 참조를 대상 계정 모델에 맞추세요. 파일명 순서로 적용하되, 아발론 비밀 상태의 직접 조회 권한과 Realtime 신호의 접근 범위, 보드게임 정책 및 Realtime publication을 확인하세요. 보드게임 구독 대상은 boardgames, boardgame_tiles, boardgame_tile_next, boardgame_gold_cards입니다. 아발론 아바타는 profileImage 버킷을 참조합니다.
5. 기존 클라이언트는 NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY, SUPABASE_SERVICE_ROLE_KEY를 참조합니다. 마지막 키는 서버에서만 사용합니다.
6. 아발론은 방 상태가 서버에 있고 개인 메모는 브라우저에 저장합니다. 보드게임은 보드 정의와 편집 변경을 공유하지만 실제 플레이의 턴·말 위치·점수는 브라우저에 저장합니다. 여러 기기에서 한 판을 진행하는 기능은 별도 구현 범위입니다.
